# Final-Year-Project_Sentiment-Analysis-on-Malaysian-Financial-Digital-Payment-in-2025

My final year project. Made some analysis on the sentiment and perception among Malaysian towards a few financial digital applications.

## Digital App
- myASNB
- Touch 'n Go e-Wallet
- KWSP i-Akaun

## Tools 
- Excel
- Python
- RStudio
- Instant Data Scraper

## Machine Learning
- Logistic Regression
- NLP
- Latent Dirichlet Allocation (LDA)
